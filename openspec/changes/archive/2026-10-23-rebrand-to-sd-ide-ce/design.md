## Context

Имя продукта IDEA Community задаётся в двух местах:

1. `community-resources/resources/idea/IdeaApplicationInfo.xml`, элемент `<names product="IDEA" fullname="IntelliJ IDEA" script="idea" …/>`. Из него `ApplicationNamesInfo` берёт `getFullProductName()`, и всё, что видит пользователь, читается отсюда.
2. `build/src/org/jetbrains/intellij/build/IdeaCommunityProperties.kt`:
   - `getSystemSelector` → `IdeaIC<major>.<minor>`, это имя каталогов настроек и кэшей;
   - `getBaseArtifactName` → `ideaIC-<build>`, `getOutputDirectoryName` → `idea-ce`;
   - `ideaCommunityMacCustomizer`: `bundleIdentifier = "com.jetbrains.intellij.ce"`, `rootDirectoryName = "IntelliJ IDEA OSS.app"`;
   - `ideaCommunityWindowsCustomizer`: `fullName`, `installDirNameHandler`;
   - `ideaCommunityLinuxCustomizer`: `rootDirectoryName = "idea-oss"`.

## Goals / Non-Goals

**Goals:**
- Пользователь видит `SD_IDE CE` вместо IntelliJ IDEA.
- `.app`, `.dmg` и архивы названы по-новому.
- SD_IDE CE не делит bundle id и каталоги настроек с официальной IDEA.

**Non-Goals:**
- EAP-варианты иконок (`*_EAP.*`, `idea-ce-eap*.svg`): сборка релизная (`eap="false"`), и они не используются.
- `install.ico`, `uninstall.ico`, `logo.bmp`, `headerlogo.bmp` установщика Windows и фон `.dmg`: отдельная задача.
- Имя скрипта и бинарника `idea`, `idea.vmoptions`, переменные `IDEA_*`: на них опираются инструменты, и пользователь их не видит в интерфейсе.
- Префикс сборки `IC`, `platformPrefix = "Idea"`, ID модулей и плагинов: от них зависит совместимость плагинов.
- Строки «IntelliJ» внутри бандл-плагинов и справки.
- Компания `JetBrains s.r.o.` в `<company>` (правообладатель) и корень каталога настроек `JetBrains/`.
- Подпись и нотаризация.

## Decisions

1. **`fullname="SD_IDE CE"` целиком, а не `fullname="SD_IDE"` + `edition="CE"`.** Платформа почти везде показывает `getFullProductName()` без редакции. С `edition` в заголовке и в About было бы просто `SD_IDE`, что противоречит требованию.
2. **`product="IDEA"` (короткое имя) не меняется.** Из него `ProjectUtil.getUserHomeProjectDir()` строит папку проектов по умолчанию. С `SD_IDE` она стала бы `~/Sd_ideProjects`, и это сломало бы требование «функциональность не меняется». Видимое имя берётся из `fullname`.
3. **Новый system selector `SDIDECE<major>.<minor>`.** Альтернатива — оставить `IdeaIC…`. Тогда SD_IDE и официальная IDEA CE делили бы настройки, плагины и индексы, и при разных версиях данные могли бы испортиться. Этого нельзя допустить, поэтому селектор меняем.
4. **Новый bundle id `com.sdide.ce`.** С прежним id macOS считает это приложение официальной IDEA: Launch Services, Gatekeeper и права в TCC смешиваются. Значение подтверждено пользователем.
5. **Артефакты `sdide-ce-<build>`, каталог вывода `sdide-ce`, `.app` `SD_IDE CE.app`, корень Linux `sdide-ce`, Windows `SD_IDE CE`.** Переименовываются только строки в customizer'ах, сами классы и структура остаются.
6. **Одна картинка для заставки и иконки, целиком, на прозрачном фоне** (решение пользователя). Скрипт `assets/make_images.py` (Pillow + numpy через одноразовое `uv run --with`, в проект ничего не добавляется):
   - удаляет белый фон, связанный с краем картинки (заливка от краёв), поэтому белые буквы «HADOOP» и бивни остаются непрозрачными;
   - сглаженную кромку на стыке с жёлтой обводкой переводит в полупрозрачность и раскладывает цвет обратно, без белой каймы;
   - срезает пустые поля по прозрачности, а сам логотип не трогает;
   - вписывает результат с прозрачными отступами в `generated/idea_community_logo.png` (640×400, поле 5%), `generated/idea_community_logo@2x.png` (1280×800) и `sd-icon-1024.png` (1024×1024, поле 4%).
   Внутри скрипта есть assert'ы: углы прозрачны, буквы непрозрачны, фон удалён.
   Почему не `sips`: он не умеет делать прозрачность. Альтернатива — ручная правка в редакторе — не воспроизводится.
7. **Логотип заставки: заменить содержимое файлов, а не путь.** `<logo url="/idea_community_logo.png"/>` остаётся, `@2x` платформа берёт сама.
8. **Форматы иконок из `sd-icon-1024.png`.**
   - `.icns`: `make_images.py` нарезает `generated/product.iconset` (16…512 и `@2x`), затем штатный `iconutil -c icns`.
   - `.ico` (Windows: 16…256) и `product_128.png` (Linux): тот же скрипт через Pillow; `sips` не умеет записывать многоразмерный `.ico`.
   - `idea-ce*.svg`: платформа требует SVG, а исходник растровый. SVG-обёртка с PNG внутри (`<image href="data:image/png;base64,…">`) нужного размера (64, 16, 32). shortcut: растр в SVG не масштабируется идеально; если иконка в UI будет мутной, нужна векторизация.
9. **URL-схема `idea://` остаётся.** Её смена ломает интеграции «открыть в IDE». Конфликт с официальной IDEA проявится, только если обе установлены сразу, и пользователь его не видит.

## Risks / Trade-offs

- [Внутренние проверки сборки могут ожидать старые имена (например, `checkExecutablePermissions`, product-info, тесты раскладки)] → после правки собрать mac aarch64 и исправить только реально упавшие проверки.
- [Автообновление по-прежнему ходит на `download.jetbrains.com/idea/` с кодом `IC` и может предложить обновить SD_IDE до официальной IntelliJ IDEA] → в этой задаче не меняем: функциональность сохраняется по требованию. Отключение обновлений — отдельное решение.
- [SVG-рендерер платформы (JSVG) может не поддерживать встроенный `<image>` с data URI] → проверить иконку в About и на экране приветствия; если её нет, векторизовать голову слона.
- [Фон `.dmg` и картинки установщика Windows остаются от IntelliJ] → Non-Goal, вынесено в Open Questions.
- [Логотип подписан «HADOOP SDP», а продукт называется `SD_IDE CE`] → используется как есть, по решению пользователя.
- [Поверх заставки платформа рисует прогресс-бар у нижнего края] → проверить, что он не закрывает надпись; при необходимости увеличить нижний отступ.
- [Окно заставки может не поддерживать прозрачность и показать прозрачные области чёрными или серыми] → проверить при запуске; если вид плохой, залить фон заставки однотонным цветом (это решение пользователя) — меняется одна строка в `fit()`.
- [На 16–32 px надпись нечитаема, и эмблема превращается в мелкое пятно] → принято пользователем: одна картинка везде.
- [Строки «IntelliJ IDEA» в текстах плагинов и в ссылках на справку] → не трогаем: переименование всего бандла — это форк, а не ребрендинг.
- [Пользователь потеряет настройки предыдущей локальной сборки] → проверено по `idea.log` первого запуска: `ConfigImportHelper` по префиксу `SDIDECE` ничего не находит (`candidates: []`), но мастер первого запуска (`JbImportServiceImpl`) находит `IdeaIC2026.2` и предлагает импорт.
- [Удалённая разработка вычисляет папки по коду `IC` как `IdeaIC<версия>` (`ProductPaths.kt`)] → в этом режиме SD_IDE не используется; Non-Goal.
